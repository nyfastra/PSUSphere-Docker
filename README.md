# PSUsphere

## Project Description
PSUsphere is a website built with Django to help manage student and school group data. It makes it easy to keep track of colleges, course programs, student names, and who belongs to which campus group.

## Key Features
* *School Directory:* Easily see all university colleges and their course programs.
* *Student Lists:* Save student details like names, IDs, and what they are studying.
* *Club Tracker:* Keep a record of all campus groups and organizations.
* *Member Lists:* Track which students belong to which clubs and when they joined.
* *Easy Admin Tool:* A clean admin dashboard with search bars and filters to find information fast.
